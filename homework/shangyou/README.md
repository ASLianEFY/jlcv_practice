# 绿色球体追踪与运动状态估计 (RoboMaster 视觉算法作业)
deepseek

## 1. 项目简介
本项目基于 C++ 与 OpenCV 编写，旨在从视频中识别出绿色的球体，并实时标注其轮廓、运动方向以及运动速度（以红色箭头长短表示）。针对画面中容易出现的绿色圆柱体干扰，算法加入了多重几何特征过滤机制。

## 2. 核心算法流程
1. **颜色空间转换**：将视频帧从 BGR 转换到 HSV 色彩空间，利用绿色的 H 通道范围进行二值化分割，有效抵抗光照变化。
2. **形态学处理**：使用开运算（去噪）和闭运算（补洞）对二值化掩膜进行处理，使目标轮廓更完整。
3. **几何特征过滤 (防干扰)**：针对绿色的圆柱体干扰，算法依次对候选轮廓进行判定：
   - **面积过滤**：剔除过小（噪点）和过大（背景或大柱子）的轮廓。
   - **圆形度 (Circularity)**：计算 \(4\pi \times Area / Perimeter^2\)，剔除长条形或不规则形状。
   - **长宽比 (Aspect Ratio)**：计算外接矩形的宽高比，球体通常接近 1.0，剔除细长物体。
   - **填充度 (Fill Ratio)**：计算面积与外接矩形面积的比值，球体约为 0.78，进一步过滤异形。
4. **目标锁定与打分机制**：为防止误锁圆柱体，算法引入了距离锁定机制。若上一帧已锁定目标，当前帧优先寻找距离上次位置 150 像素内的目标；若无，则对所有符合形状特征的轮廓按“圆形度 × 面积”打分，选取得分最高的作为最终目标。
5. **速度估计与平滑**：
   - 计算质心位移与时间差 \(dt\) 的比值，得到瞬时速度。
   - 采用指数平滑算法（EMA）对位置和速度进行平滑，防止箭头抖动。
   - 箭头的长度与平滑后的速度成正比，方向与速度向量一致。

## 3. 编译与运行环境
- **系统**: Ubuntu (Linux)
- **依赖**: C++14, OpenCV 4.x
- **编译命令**:
  ```bash
  g++ main.cpp -o main `pkg-config --cflags --libs opencv4`
```
