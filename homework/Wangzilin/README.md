## 实现过程

1. **基础版**：按 PPT 流程实现——HSV 颜色分割 → 形态学去噪 → 面积 / 圆度 / 长宽比筛选轮廓（用**圆度**区分绿球和画面里的绿色圆柱）→ 速度预测 + 距离门控 + 丢帧外推 → 画圆、箭头和速度。
2. **贴边漏检**：不采用"贴边就全局放宽阈值"（会把绿色圆柱也收进来），改成**严格优先**，只有找不到严格候选时，才在**预测位置附近**放宽兜底 → 丢帧 **12 → 0**。
3. **贴边偏心**：球被切掉一半时质心会向画面内侧偏，画出的圆也跟着向内靠，因此改用**预测与观测加权融合**（位置 = 预测 + α × (观测 − 预测)）→ 贴边处与真实圆心的平均误差 **6.08 → 3.82 px**。
4. **折返抖动**：球在边缘折返时会出现明显抖动，用**可见面积趋势**判断球是在离开还是回到画面，回到画面时提高观测权重、让速度及时跟上 → 最大误差 **12.07 → 6.76 px**。

## 已知局限

阈值按本视频调定（换光照 / 背景需重新标定）；速度是像素/秒，不是物理速度；同一时刻只跟踪一个球。
