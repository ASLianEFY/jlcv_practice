# 绿球识别与运动标注 (SWJ)

识别视频 `homework.mp4` 中的绿色小球，画圆框标出位置，用箭头标注运动方向和速度：
- 箭头方向 = 小球运动方向
- 箭头长度 ∝ 速度大小（越长越快，越短越慢）
- 旁边标注数值（像素/秒，px/s）

## 实现思路（极简，每一行都能看懂）

1. **HSV 颜色分割**：把图片转 HSV 空间，按绿色色相提取绿色区域
2. **形态学去噪**：开运算去小噪点，闭运算补小空洞
3. **轮廓筛选**：面积 + 圆度 + 长宽比，把「绿球」和画面里的「绿色圆柱」区分开
4. **帧差算速度**：`速度 = (本帧位置 − 上一帧位置) × FPS`，单位 px/s
5. **画标注**：绿色圆框 + 红色箭头（方向 = 速度方向，长度 ∝ 速度大小）+ 速度文字

## 运行

依赖：Python 3、OpenCV、NumPy

```bash
pip install opencv-python numpy
```

在仓库根目录 `jlcv_practice/` 下执行：

```bash
python3 homework/week1-git-and-cpp/SWJ/green_ball_tracker.py
```

预览窗口中按 `q` 键退出。程序固定读取仓库根目录的 `homework.mp4`。
