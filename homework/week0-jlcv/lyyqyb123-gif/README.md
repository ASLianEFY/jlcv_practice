# week0-jlcv 作业：绿球检测与运动标注

## 作业要求

识别 `homework.mp4` 中的绿球，并用箭头标注其运动方向和速度变化：

- 箭头方向 = 小球的运动方向
- 箭头长度 = 速度大小（越长越快，越短越慢）

## 运行环境

- Python 3.8+
- OpenCV（`opencv-python`）
- NumPy

安装依赖：

```bash
pip install -r requirements.txt
```

运行（在仓库根目录）：

```bash
python3 homework/week0-jlcv/lyyqyb123-gif/detect_green_ball.py
```

默认读取仓库根目录的 `homework.mp4`，输出到脚本所在目录：

- `output_annotated.mp4`：带标注的视频
- `trajectory.csv`：逐帧位置、速度、加速度数据

也可以手动指定路径：

```bash
python3 detect_green_ball.py --input /path/to/homework.mp4 --output result.mp4
```

## 算法流程

1. **颜色分割**：BGR 转 HSV，用绿色范围 `(35,60,50) ~ (90,255,255)` 做阈值；
2. **去噪**：5×5 形态学开运算 + 闭运算；
3. **候选筛选**：保留面积 400~40000、圆度 > 0.5、宽高比 0.70~1.40 的轮廓。
   绿色圆柱的面积更大、宽高比偏离 1，因此被排除；
4. **跟踪**：
   - 首帧：按“圆度 + 宽高比接近 1 + 面积适中”选最像球的候选；
   - 后续帧：用“上一帧位置 + 速度”预测，再在预测点附近做最近邻匹配，
     并叠加形状得分，避免跳到绿色圆柱上；
   - 短暂丢失时按预测位置滑行，连续丢失超过 15 帧后重新捕获；
5. **运动学计算**：
   - 轨迹做 15 帧中心滑动平均，抑制手持相机抖动；
   - 速度 = 位置梯度 × fps；
   - 加速度 = 速度梯度 × fps；
6. **可视化**：
   - 洋红色圆圈标记绿球；
   - 箭头长度随速度自适应缩放，方向为速度方向；
   - 箭头颜色：红色=加速，蓝色=减速，黄色=速度基本不变；
   - 文字显示当前速度与加速度；
   - 右下角绘制随时间增长的速度曲线。

## 结果

- 视频：1280×720，30 fps，共 473 帧（约 15.8 s）
- 检测率：**100%**（473/473 帧）
- 速度范围：约 **16 ~ 757 px/s**，平均约 **336 px/s**

> 视频为手持拍摄，相机的晃动会叠加到表观速度上，因此速度数值偏大；
> 箭头反映的是图像平面中的运动。若需要球相对桌面的真实运动，可进一步
> 用背景特征点估计相机运动并做补偿（作为后续改进方向）。
